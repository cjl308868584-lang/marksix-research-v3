# 六合智研

香港六合彩与新澳门六合彩的实时开奖、历史记录、高概率分类事件研究、滚动回测和逐期学习站点。

## 核心能力

- 北京时间实时时钟与开奖日程
- 开奖前 3 分钟自动开启开奖台，结果确认后逐球揭晓
- 香港与新澳门双彩种历史 API、第三方来源交叉校验与降级样本
- 每颗号码球下方常显生肖，历史记录支持分批加载
- 针对 320–430px 手机屏幕优化的开奖卡片、历史卡片与底部导航
- 研究系统固定预测四项：`6+1生肖覆盖`、`6+1尾数覆盖`、`指定位置单双`、`指定位置大小`
- 正式研究接口不输出具体号码、号码 Top3 或“未出现”型高命中指标
- 每项同时公开精确随机基线、概率、Brier、log-loss、快中慢证据和专家权重
- 精确随机基线、可解释规则、正则化逻辑回归和黑盒挑战者四专家并行
- 开奖后严格执行“先结算旧预测，再学习新样本”，不会用本期开奖结果回填本期评分
- 冠军/挑战者版本化保存；挑战者需连续前瞻验证通过后才能替换冠军
- GPT‑5.6 Sol 只负责把结构化证据与复盘翻译成中文，不得修改冻结概率
- 严格结构化输出、服务端密钥、匿名限流与 D1 报告持久化
- 同一期已完成报告刷新后自动恢复，不会重复调用大模型
- 已核验开奖号自动结算冻结四项事件，以按期去重、Beta-Binomial 收缩和调权上限执行在线学习
- 无未来数据泄漏的 walk-forward 回测，并与理论随机基准对照
- 大模型异常时保持同结构的本地证据报告，不让页面失效
- 独立“近30期条件规律”页面只研究 `条件 A(t) → 下一期结果 B(t+1)`，不再把近期频率、热号或无条件遗漏当作规律
- 每条规律必须在最新30期窗口内被当前条件触发，并公开 A、B、历史触发、命中/失败、B自身随机基准、后验提升、p值和FDR q值
- 近期规律允许展示 `3次触发、2次命中` 等待验证小样本，但只有 `q≤0.10` 才标记“近期强证据”；不会写入正式策略概率或模型权重
- 每期开奖任务先结算上一期冻结规律，再丢弃最旧一期、重扫最新30期并幂等冻结下一期；没有合格规律时保存有效空结果

## 本地运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
```

刷新双彩种本地历史快照：

```bash
npm run data:sync
```

## 环境变量

复制 `.env.example` 为 `.env.local`，按需配置：

- `AI_API_KEY`：AI 服务密钥
- `AI_BASE_URL`：OpenAI 兼容 API 根地址
- `AI_MODEL`：模型名称，当前推荐 `gpt-5.6-sol`
- `AI_REASONING_EFFORT`：仅供 `depth=deep` 的 API 请求使用，默认 `medium`；手机端标准报告固定使用低延迟 `low`
- `AI_SAFETY_SALT`：用于匿名化访问指纹的随机密钥

没有密钥时站点仍可运行，并会明确标注统计模式或单源状态。

AI 接口只接受彩种、窗口和固定分析维度；历史数据、事件概率、证据指数、模型权重及回测均在服务端计算。大模型仅负责跨维度归纳、冲突解释和总结，不能添加预测项目、修改概率或伪造命中率。

v3 使用 D1 永久保存开奖前事件账本、逐项评分、学习任务、规则状态、模型权重和模型制品。每个目标期只冻结一份四项预测；重复结算使用幂等任务 ID 返回同一结果。数据异常或训练失败时继续使用上一冠军与随机基线，不覆盖已冻结预测。

研究读取接口：

- `GET /api/research/forecast`
- `GET /api/research/reviews`
- `GET /api/research/performance`
- `GET /api/research/models`
- `GET /api/research/learning-runs`
- `GET /api/research/patterns`

内部自动任务使用 `POST /api/internal/research/settle-and-learn`，请求需在五分钟窗口内通过 HMAC-SHA256 签名。
同一个签名任务同时完成四项策略学习与近30期规律重扫，不另设第二个定时器。公开研究页面只读取冻结结果，刷新不会触发扫描或写入数据库。

## 使用边界

本项目只提供第三方历史数据研究与娱乐参考，并非官方彩票网站；不销售彩票、不接受投注，也不承诺或暗示任何收益。
