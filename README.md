# 六合智研

香港六合彩与新澳门六合彩的实时开奖、历史记录、系统统计、滚动回测和 AI 多维分析站点。

## 核心能力

- 北京时间实时时钟与开奖日程
- 开奖前 3 分钟自动开启开奖台，结果确认后逐球揭晓
- 香港与新澳门双彩种历史 API、第三方来源交叉校验与降级样本
- 每颗号码球下方常显生肖，历史记录支持分批加载
- 针对 320–430px 手机屏幕优化的开奖卡片、历史卡片与底部导航
- 号码、生肖、波色、遗漏、单双、大小、区间、重号和连号统计
- 冷热平衡、趋势延续和逆向遗漏三路候选策略
- GPT‑5.6 Sol 证据归纳报告：九维证据、三路场景、强总结与反方校验
- 严格结构化输出、服务端密钥、匿名限流与 D1 报告持久化
- 同一期已完成报告刷新后自动恢复，不会重复调用大模型
- 已核验开奖号自动结算冻结报告，并以按期去重、先验收缩和调权上限执行在线学习
- 无未来数据泄漏的 walk-forward 回测，并与理论随机基准对照
- 大模型异常时保持同结构的本地证据报告，不让页面失效

## 本地运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
```

刷新双彩种本地历史快照：

```bash
npm run data:sync
```

## 环境变量

复制 `.env.example` 为 `.env.local`，按需配置：

- `AI_API_KEY`：AI 服务密钥
- `AI_BASE_URL`：OpenAI 兼容 API 根地址
- `AI_MODEL`：模型名称，当前推荐 `gpt-5.6-sol`
- `AI_REASONING_EFFORT`：仅供 `depth=deep` 的 API 请求使用，默认 `medium`；手机端标准报告固定使用低延迟 `low`
- `AI_SAFETY_SALT`：用于匿名化访问指纹的随机密钥

没有密钥时站点仍可运行，并会明确标注统计模式或单源状态。

AI 接口只接受彩种、窗口和固定分析维度；历史数据、候选号码、证据指数、策略优先级及回测均在服务端计算。大模型仅负责跨维度归纳、冲突解释和总结，不能自行添加号码或伪造命中率。

报告持久化只接受数据质量门禁通过且 AI 正常完成的开奖前报告；同一目标期已有的兼容旧版存档与官方生肖方向会优先恢复，部署新算法也不能重开覆盖。访问分析页面时，系统会用最新的交叉核验结果结算相应报告；在线学习只使用已核验、已结算、早于本次截止时间且按目标期最早冻结记录去重的最近 365 期。少于 12 个独立目标期时只积累样本，不调整权重；赛后更新只从下一份新报告开始参与判断，不倒改已冻结报告，也不继承或改写正式的独立留出结论。

## 使用边界

本项目只提供第三方历史数据研究与娱乐参考，并非官方彩票网站；不销售彩票、不接受投注，也不承诺或暗示任何收益。
