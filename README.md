# 六合智研

香港六合彩、澳门六合彩与新澳门六合彩的实时开奖、历史记录、系统统计、滚动回测和 AI 多维分析站点。

## 核心能力

- 北京时间实时时钟与开奖日程
- 开奖前 3 分钟自动开启开奖台，结果确认后逐球揭晓
- 三彩种免费历史 API、第三方来源交叉校验与降级样本
- 每颗号码球下方常显生肖，历史记录支持分批加载
- 针对 320–430px 手机屏幕优化的开奖卡片、历史卡片与底部导航
- 号码、生肖、波色、遗漏、单双、大小、区间、重号和连号统计
- 冷热平衡、趋势延续和逆向遗漏三路候选策略
- GPT‑5.6 Sol 深度报告：九维证据、三路场景、强总结与反方校验
- 严格结构化输出、服务端密钥、匿名限流与 30 分钟结果缓存
- 无未来数据泄漏的 walk-forward 回测，并与理论随机基准对照
- 大模型异常时保持同结构的本地证据报告，不让页面失效

## 本地运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
```

刷新三彩种本地历史快照：

```bash
npm run data:sync
```

## 环境变量

复制 `.env.example` 为 `.env.local`，按需配置：

- `AI_API_KEY`：AI 服务密钥
- `AI_BASE_URL`：OpenAI 兼容 API 根地址
- `AI_MODEL`：模型名称，当前推荐 `gpt-5.6-sol`
- `AI_REASONING_EFFORT`：推理强度，默认 `medium`
- `AI_SAFETY_SALT`：用于匿名化访问指纹的随机密钥
- `BOYI_API_TOKEN`：澳门历史数据第二核验源密钥

没有密钥时站点仍可运行，并会明确标注统计模式或单源状态。

AI 接口只接受彩种、窗口和固定分析维度；历史数据、候选号码、证据指数及回测均在服务端计算。大模型仅负责跨维度归纳、策略排序、冲突解释和总结，不能自行添加号码或伪造命中率。

## 使用边界

本项目只提供第三方历史数据研究与娱乐参考，并非官方彩票网站；不销售彩票、不接受投注，也不承诺或暗示任何收益。
