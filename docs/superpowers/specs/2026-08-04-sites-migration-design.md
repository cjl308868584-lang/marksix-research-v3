# 六合智研 v3 迁回 Sites 与模型更新设计

## 目标

将当前生产系统从独立 Cloudflare Worker/D1 迁移到当前登录的
`c308868584` Sites 账户，保留香港与新澳门的四项高概率策略、冻结账本、
逐期复盘和模型学习能力。迁移完成后删除独立 Cloudflare 资源和对应自动任务，
避免继续产生失效任务或双写数据。

## 迁移边界

- 保留现有手机端开奖、研究、复盘页面与四项高概率事件。
- 不恢复具体号码、号码 Top3 或其他低概率预测。
- 香港与新澳门继续完全分离训练和结算。
- 旧 Cloudflare D1 在删除前必须导出结构与数据，并保存到本地迁移备份目录。
- 独立 Cloudflare Worker、D1、Worker secrets 及 GitHub Cloudflare 工作流只在
  Sites 新版本通过生产验证后删除。
- 旧 `v308868584` Sites 只作为一次性迁移来源；新站连续完成预测与复盘后再停止依赖。

## 目标架构

Sites 负责页面、API、持久化数据库和模型运行。网页请求只读取已冻结预测；
训练和结算只能通过受保护的内部任务执行。每次任务严格遵循：

1. 读取开奖前冻结的四项预测。
2. 只在结果达到核验等级后结算。
3. 保存逐项 Brier、log-loss、命中和误差归因。
4. 更新规则后验和模型权重。
5. 生成下一期四项高概率事件。
6. 保存新数据、模型和预测版本，再生成持久化中文总结。

任何一步失败都保留上一冠军和上一份冻结记录，不得写入半成品预测。

## 模型更新

- 保留精确随机基线、可解释规则、逻辑回归和挑战者四类专家。
- 随机基线权重不得低于 25%，单模型不得高于 50%。
- 单期权重变化不超过 10 个百分点，高置信错误由 log-loss 加重处罚。
- 正式预测固定为：6+1生肖覆盖、6+1尾数覆盖、指定位置单双、指定位置大小。
- 先结算旧预测，再学习本期开奖结果，最后生成下一期；禁止数据穿越。
- 模型更新后必须通过时间滚动验证；失败时继续使用旧冠军。
- AI 只解释结构化结论，不得修改概率、命中和证据等级。

## 数据迁移与删除顺序

1. 导出 Cloudflare D1 的完整 SQL/JSON 备份并记录校验哈希。
2. 构建 Sites 数据迁移包，导入冻结预测、复盘、学习运行、权重和规则状态。
3. 在 `c308868584` 创建或接管 Sites 项目，配置持久化绑定与运行密钥。
4. 发布新版本并验证香港、新澳门页面与全部读取接口。
5. 执行一次幂等结算任务，确认能保存复盘并生成下一期四项事件。
6. 验证刷新不重算、重复任务不重复学习、手机页面无横向溢出。
7. 停止 GitHub Cloudflare 定时与部署工作流。
8. 删除独立 Cloudflare Worker 和 D1；保留本地备份及 GitHub 源码。
9. 清除不再使用的 Cloudflare/GitHub secrets。

## 验证标准

- 新 Sites URL 可公开访问，默认显示新澳门。
- 香港和新澳门均返回且只返回四项高概率事件。
- 已开奖期可看到开奖前概率、实际结果、2/4 类命中统计及概率评分。
- 同一 taskId 重放不会新增第二次学习记录。
- 未核验结果不会结算或更新模型。
- 结算后下一目标期号正确，冻结时间早于预定开奖时间。
- 数据版本、模型版本、权重变化和复盘可永久重建。
- 360px 手机宽度无横向溢出。
- Cloudflare 资源删除后，新站核心接口仍正常工作。

## 回退方案

删除 Cloudflare 前记录 Sites 的已验证版本。若 Sites 发布或数据导入失败，停止删除步骤，
继续使用现有 Cloudflare 只读站点。若删除后发现问题，使用导出的 D1 备份和对应 Git 提交
恢复到新的 Sites 版本，不依赖已删除的 Worker。
