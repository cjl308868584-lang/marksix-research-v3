# 六合智研：近30期条件规律引擎重构设计

## 目标

“近30期规律”不再展示某个生肖、尾数、波色或头数自身的冷热、频率或简单重现。系统研究的唯一问题是：

> 当历史条件 A 出现时，下一期结果 B 的概率是否高于 B 自身的精确随机基准；并且最新一期已经满足 A，因此该规律对下一期具有直接含义。

页面仍是独立的研究实验室，不改变 v3 正式四项策略的冻结概率。

## 统计窗口与时间顺序

- 香港与新澳门分别使用各自最新30期已核验开奖。
- 窗口随每期核验结果严格滚动：加入最新一期，同时丢弃最早一期。
- 历史触发在时间上表示 `A(t) → B(t+1)`；B 的开奖结果绝不能参与 A 的计算。
- 最新一期只用于判断 A 当前是否成立；目标是尚未开奖的下一期。
- 不足30期时冻结“数据不足”，不以低质量历史补足。

## 事件 B

结果事件沿用高概率分类，不预测号码：

- 6+1至少出现一个指定生肖。
- 6+1至少出现一个指定尾数。
- 6+1至少出现3个指定波色号码。
- 6+1至少出现2个指定头数号码。

每个事件使用无放回组合计算自身精确随机基准。生肖映射按对应开奖日期计算。

## 条件 A 与规则家族

### 1. 单条件传导

同一期出现一个来源事件，研究下一期另一个结果事件：

`本期 A 出现 → 下一期 B 出现`

A 与 B 必须是不同事件。它们可以属于相同分类，也可以跨生肖、尾数、波色和头数传导。

### 2. 双条件交集传导

同一期同时满足两个不同来源事件，研究下一期结果：

`本期 A1 与 A2 同时出现 → 下一期 B 出现`

为限制组合爆炸：A1和A2必须来自不同分类，B不能与任一来源事件相同，前置条件最多两个。

### 3. 同事件节奏规律

同一事件最近2至5期形成明确状态序列，研究下一期同一事件：

- `连续N期未出现 → 下一期回补`
- `连续N期出现 → 下一期延续`
- `出现/未出现状态序列 → 下一期出现`

连续回补必须要求该遗漏段之前曾出现，连续延续必须要求该连续段之前未出现，避免把更长序列重复统计成多个等价规则。

## 明确排除

- 最近30期出现次数、热度或排行榜。
- 没有前置条件A的结果频率。
- “前2至5期出现过，所以推测重现”的简单滞后规则。
- 单独一期的自我延续 `B(t) → B(t+1)`；这类结果过于接近热号解释。
- 具体号码、号码Top3和单位置小概率结果。
- 未在最新历史状态触发、不能用于下一期的规则。

## 规则筛选与证据等级

对每条当前已触发的规则，在同一30期窗口中枚举所有严格的历史 `A(t) → B(t+1)` 样本。

基础展示门槛：

- 历史触发不少于3次。
- 原始命中率高于B的平均精确随机基准。
- 原始提升不少于5个百分点。
- Beta-Binomial向B基准收缩后仍高于基准。

系统同时计算精确上尾概率，并对本期全部候选做BH-FDR校正：

- `q ≤ 0.10`：标记“近期强证据”。
- `q > 0.10`：标记“待验证规律”，即使原始结果是2/3，也不能称为统计显著。

候选按证据等级、收缩后提升、触发次数排序。数学等价规则使用规范化条件JSON生成稳定ID并合并，不重复计数。

## 卡片必须说明什么

页面更名为“近30期条件规律”。每张卡片以规则关系为视觉主体：

1. **完整规律**：`当A时 → 下一期B`。
2. **本期为何触发**：列出最新一期或最近状态序列的具体期号、事件、实际数量与是否满足。
3. **30期历史表现**：触发次数、命中、失败、原始命中率、B随机基准、提升、收缩后概率、p值、q值。
4. **逐次审计**：每次历史触发都显示来源期A的实际条件、目标期B的实际结果及命中/失败。

旧的30格“出现/未出现”热度式状态条从主卡片移除。分类筛选仍保留，但它筛选的是目标B的分类，不代表热号分类。

## 空状态与冻结

- 没有规则达标时，冻结并展示“本期没有符合门槛的条件规律”。
- 不得反复重跑直到出现结果。
- 新引擎版本生成新的不可变运行；旧版运行保留用于审计，但读取接口只返回与当前目标期和当前引擎版本匹配的运行。
- 上一期冻结规律开奖后逐条结算，再重扫新的30期窗口。

## 验收测试

- 人工构造 `A出现 → 下一期B出现` 三次触发两次命中的案例能被发现。
- 同一事件的连续三期遗漏后回补能被发现，并写出完整条件。
- 无条件频率、热号、简单滞后和一期自我延续不会生成。
- 每条展示规则都含明确A、明确下一期B、本期触发证据和逐次审计。
- 规则只使用目标期开奖之前的数据。
- 30期窗口新增一期后准确丢弃最早一期。
- p值和BH-FDR计算可复现，2/3小样本不会被误标为“近期强证据”。
- 当前目标期没有新版运行时不得回退旧引擎结果。
- 360像素手机页面无横向溢出。
