# 近30期规律逐期账本与赔率价值设计

## 目标

把当前按请求即时计算的结果汇总升级为开奖前冻结、开奖后结算、可逐期重建的结果级账本，并在汇总上方展示赔率价值分析。

## 冻结对象

- 6+1 单肖：马净赔率 0.75，其余净赔率 1。
- 6+1 单尾：0尾净赔率 1，其余净赔率 0.75。
- 6+1 二连肖：两个生肖都在6+1中至少出现一次；含马净赔率 2，不含马净赔率 3。
- 6+1 三连肖：三个生肖都在6+1中至少出现一次；含马净赔率 7，不含马净赔率 9。
- 特码号码：当前特码交集榜前15名，每个号码净赔率 47。

每个冻结对象保存目标期、结果标识、支持策略数、历史触发/命中/失败、模型参考概率、赔率、盈亏平衡概率、期望收益、排序和冻结时间。组合只从当前有支持的生肖结果生成；组合概率使用各生肖事件对应规则的历史审计目标期交集计算，不能把两个或三个单肖命中率相乘。

## 概率与价值

- 盈亏平衡概率：`1 / (净赔率 + 1)`。
- 每投注1单位期望收益：`p × 净赔率 - (1 - p)`。
- 单项概率使用结果级历史审计的 Beta 收缩均值：先验以该玩法精确随机基线为中心，强度为4次等效样本。
- 单肖、单尾直接由汇总结果的触发/命中计算。
- 二连肖、三连肖由同一目标期同时满足所有生肖的联合审计计算。
- 特码号码由支持该号码的特码分类事件按目标期去重后计算；同一期只计一次。
- 不再设置最少20期或FDR门槛。只要期望收益大于0即显示“符合赔率价值”，否则显示“不符合”。页面始终同时展示样本数，避免隐藏小样本。

## 持久化与结算

新增不可变表 `rolling_pattern_consensus_ledger`，唯一键为 `(run_id, product_id)`；新增 `rolling_pattern_consensus_scores`，唯一键相同。冻结运行时生成账本，重复任务用 `INSERT OR IGNORE` 修复缺失子记录而不改变既有快照。

开奖后按已核验的目标期开奖结算：保存命中、实际开奖结果、单位利润和结算时间。覆盖玩法根据6个正码加特码判断；特码号码根据特码判断。重复结算不重复累计。

读取当前页时返回当前价值榜与最近历史账本。旧运行可以从已保存的信号幂等补建账本，并在后续自动任务中用已有开奖补结算。

## 页面

在“本期规律总统计”上方增加“赔率价值分析”：按单位期望收益排序，展示玩法、结果、赔率、盈亏平衡概率、参考概率、期望收益、支持策略与状态。6+1页展示单肖、单尾、二连肖、三连肖；特码页展示前15个号码。

增加“逐期汇总结算”区域，按目标期展示冻结项目及开奖后的命中/失败、单位盈亏。原有规律汇总、筛选和逐条审计保留。

## 安全边界

系统只进行数学价值研究，不自动下注、不提供投注金额、不承诺收益。当前概率来自近30期筛查及逐期记录，小样本仍可能大幅波动。
